## Agent skills

### Issue tracker

Issues live as GitHub Issues in `Shoreasg/Friday-Mahjong-Scoreboard`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default 5-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), label strings match role names exactly. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout — one `CONTEXT.md` + `docs/adr/` at the repo root (created lazily by `/domain-modeling` when needed). See `docs/agents/domain.md`.
